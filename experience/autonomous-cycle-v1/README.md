# Первая автономная попытка: ABORTED

Исходное состояние — проверенный G20. Runtime и двенадцать строгих критериев
зафиксированы локальным commit `14b9a2cef98c96744e85704ad302bd828e6bef7f`;
идентичное дерево опубликовано commit
[`e20cdf1`](https://github.com/v37025337-pixel/nova-/commit/e20cdf126bba2925aca753871bf36d6644f73e61).

Ядро выделило подцель сравнения числовых компонентов версий из собственной
ошибки, выбрало алгоритмический механизм, сформировало поисковый запрос,
выбрало и прочитало два первоисточника. Перед синтезом сохранён `SEARCH_FROZEN`.

Оператор прервал поиск примерно через 401 секунду. Диагностика обнаружила
повторное исполнение дорогих унаследованных выражений: один SHA-256 занимал
около 0,024 секунды, а составные кандидаты заново вычисляли те же операнды.
Граница в 12000 кандидатов не ограничивала это избыточное время.

Результат — **ABORTED**, не PASS и не результат полной проверки кандидата.
Ни одного кандидата или нового поколения не получено; свежие тесты не создавались.
G20 не изменён. Экспорт соответствует всем 53 событиям прерванного состояния.
Детали: [abort.json](abort.json), [frozen-goal.json](frozen-goal.json),
[search-freeze.json](search-freeze.json), [journal.json](journal.json).

Общее исправление повторных вычислений сделано разработчиком и **не считается
мутацией Nova**. После него создан [отдельный опыт v2](../autonomous-cycle-v2/README.md)
с новым runtime и новым freeze, теми же правилами успеха и исходным G20.
Предыдущая попытка сохранена полностью. Для воспроизведения именно этого
журнала нужен исходный commit; текущий runtime принадлежит следующему опыту.
