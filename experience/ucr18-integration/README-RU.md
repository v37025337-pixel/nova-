# Nova 0.9 с UCR 18: продолжение G22

Присланный `universal_code_reader-19.py` подключён как UCR 18.0. Сохранены
исправления байтов, графов и JSON из предыдущей интеграции. Исправлен новый
дефект seed: итоговая сортировка больше не стирает различия между испытаниями.

Runtime обновлён с v8 до v9 отдельным событием. Полный точный манифест v8
сохранён; 22 используемых метода вывода совпадают с прежним исходным кодом.
При воспроизведении старых событий сохраняется их исторический тег 16.0,
а новый поиск явно записывает UCR 18.0. Журналы не переписывались.

## Реальный запуск Nova

Продолжены все 120 событий предыдущего опыта G22. Новых задач, документов
или готовых ответов оператор не добавлял. После обновления выполнены три
обычных шага ядра.

| Проверка | Результат |
|---|---|
| Выбранная ядром цель | `source_bytes → source_url` в прежних описаниях исходников |
| Обучающие примеры | 8 |
| UCR 18 | 2408 деревьев; точного решения нет |
| Прежний поиск и контроль на той же выборке | 10654 кандидата; решения нет |
| Решение ядра | `WITHHOLD / OBSERVATION_SEARCH_EXHAUSTED` |
| Новые навыки | 0; активна G22 |
| Прежние навыки | 21; 192/192 проверок |
| Журнал | 124 события, исходные 120 сохранены точно |

Предсказуемость URL по размеру файла не доказана. Выбор полезной обучаемой
цели остаётся ограничением: правило ранжирования пар полей в этом обновлении
не менялось. Само обновление reader не является улучшением навыков Nova.

128 тестов прошли, включая новые функции reader, различие seed, сохранение
состояния и точные старые результаты поиска. Хеши 22 файлов ядра и трёх
файлов инструментов проверены. Результат отдельного процесса воспроизведения
записан в `summary.json` и `restart-stdout.json`; CI повторяет восстановление.

## Отдельный результат UCR

Новые механизмы трёхзвенной композиции и выбора стратегии проверены на
встроенных учебных задачах UCR. Они получили собственное состояние с двумя
правилами, одной стратегией и двумя примитивами. Эти примитивы не допущены
в геном Nova. Внутренние выборки используются при отборе испытаний; их
оценки не являются независимой проверкой новых возможностей Nova.

Полный отдельный отчёт: [проверка функций UCR 18](../ucr18-feature-probe/README-RU.md).

## Повторение

```bash
python -m unittest discover -s tests -v
python scripts/verify_release.py
python scripts/run_ucr_development.py --parent experience/ucr-development-v1/journal.json.gz --output /tmp/nova-ucr18
```

Для сохранённого журнала нужен Python 3.12. Новые запуски сохраняются в новом
каталоге. Точный runtime и хеш родительского архива указаны в `protocol.json`.
