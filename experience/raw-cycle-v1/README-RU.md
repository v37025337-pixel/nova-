# Сырой мир → цель → механизм → перенос → регрессия

**Один реальный цикл завершён admission и применением механизма к общей памяти.**
Runtime NOVA 1.1, общий геном Unified U2, 25 приобретённых механизмов. Это отдельная
нумерация общего ядра: родительские Nova G22 и Next G3 не переименованы в G23.

## Протокол

До любого сетевого чтения зафиксированы код runtime, SHA-256 сценария, четыре URL,
бюджет шагов и критерии. Ни один файл не был предварительно скачан для подбора
механизма. Ядро получило только массив URL, без task ID, train/answer-пар, reader,
blueprint или списка прикладных целей. Порядок URL задаёт среду; роли обучения и
переноса выбирает сам протокол ядра, по два успешных независимых origin.

Глобальное предпочтение предоставлено разработчиком: точно сохранять наблюдения,
уменьшая их длину описания. Конкретная цель, её измеренный дефицит, грамматика и
исполняемая программа выведены ядром из наблюдений. Алгоритм индукции не изобретён
ядром: это ограниченное обучение соседним байтовым подстановкам с MDL-отбором.

| Шаг | Событие журнала | Полученный результат |
| --- | --- | --- |
| 1–2 | `raw.fetch` | curl: 82 429 байт; serde_json: 86 840 байт |
| 3 | `raw.discover` | Цель уменьшить измеренную стоимость хранения с точным восстановлением |
| 4 | `raw.synthesize` | 189 правил, новый прямой и обратный Python-код; фиксация до transfer |
| 5–6 | `raw.fetch` | Gson: 65 260 байт; Pydantic: 88 976 байт; новые origin и новые хеши |
| 7 | `raw.assess` | Положительный transfer, ablation, общая регрессия, admission и применение |

Во время реального цикла обращение к общему каталогу, UCR-reader, графовому парсеру
или готовому графовому выбору целей немедленно вызвало бы ошибку. Обращений — ноль.
Функция обучения получает исключительно байтовые строки; URL и расширения файлов
не выбирают её поведение. Latin-1 используется только как взаимно однозначное
представление значений 0..255 для строковых подстановок.

## Свидетельство переноса

Полная стоимость переносимого артефакта — **17 335 байт**, включая правила,
сгенерированный исходник и идентификатор. Она начислена целиком и на discovery,
и повторно на transfer. Это строже амортизации по уже накопленной памяти.

| Метрика | Discovery | Fresh transfer |
| --- | ---: | ---: |
| Исходные байты | 169 269 | 154 236 |
| Базовое хранение с однобайтовым маркером | 169 271 | 154 238 |
| Данные новым механизмом плюс полная модель | 107 300 | 117 372 |
| Чистый выигрыш относительно базового хранения | 61 971 | 36 866 |
| Полные файлы, восстановленные точно | 2/2 | 2/2 |
| Обычный zlib, справочное сравнение | 35 937 | 34 794 |

На transfer оба файла становятся меньше. Удаление всех выведенных правил действительно
компилируется и исполняется: размер 154 442 байта, полезный выигрыш исчезает.
Проверяющая сторона раскрывает DAG правил и читает битовый поток самостоятельно,
без вызова сгенерированного обратного преобразования. Ожидаемые значения — исходные
байты независимых HTTPS-ответов. Identity прошёл бы восстановление, но не admission:
нужен положительный выигрыш после оплаты модели и необходимое влияние правил.

После admission все четыре записи активной памяти используют новый механизм:
**323 505 → 207 337 байт**, экономия 116 168 байт (35,9%). `recall` восстанавливает
их точные SHA-256. Каталог получает `raw.pack:<id>` и `raw.unpack:<id>` только после
admission. Журнал аудита хранит исходные свидетельства отдельно; его размер и
служебные JSON/SQLite-обёртки не включены в эту метрику.

## Регрессия и отрицательные проверки

- 192/192 ответов 21 прежнего навыка Nova.
- 72/72 сохранённых проверок трёх приобретённых графовых программ.
- 4/4 полных байтовых наблюдений нового механизма.
- **171 тест, 0 ошибок**, 181,750 с; девять новых проверок сырого цикла.
- Контрольные данные с шумом не создают выдуманную полезную цель.
- Непереносимый кандидат получает `WITHHOLD`; проверочные данные остаются использованными.
- Повторённое содержимое не становится свежим при смене URL.
- Общая отрицательная регрессия не позволяет записать положительный admission.
- Подменённый итог отвергается после пересчёта всей цепочки хешей.
- Подменённый исполняемый исходник и чрезмерное раскрытие грамматики отвергаются.
- Полный replay выполняется без сети. Откат сохраняет свежесть, байты и 24 прежних навыка.

Исходный пробел зафиксирован в `before.txt`: метода подачи наблюдений без задачи
не существовало. `focused.txt` и `tests.txt` содержат фактические результаты тестов.

## Граница результата

Цель принадлежит одному предоставленному классу внутренней мотивации — точному
сохранению с меньшим описанием. Прикладного каталога нет, но алгоритм индукции,
грамматика вычислений, бюджеты и admission заданы нами. Это не доказательство
спонтанного открытия произвольной смысловой задачи или самостоятельного создания
общего алгоритма мышления. zlib существенно эффективнее этого механизма.

Два transfer-файла — два файла из новых репозиториев. Их происхождение фиксируется
локальным HTTPS-захватом; подписи серверов и независимость общего происхождения
этим не доказываются. Upstream-лицензии сохранены в `live/upstream-licenses/`.
Сознание и общий интеллект не заявляются.
