# G22: свежий разнородный поток без заданной задачи

**Результат: `WITHHOLD_NO_NATIVE_DEFICIT`.** В этом эксперименте неизменённая G22
сохранила новые данные, но не выбрала системный дефицит и не сформулировала цель.
Новых поколений нет; активной остаётся G22. Отрицательный результат сохранён
вместе с исходными ответами, точными входами и журналом.

## Что проверялось

Может ли `Kernel.step()` самостоятельно назвать повторяющийся недостаток по
свежим внешним наблюдениям, когда оператор не регистрирует задачу и не передаёт
правильные ответы? До получения данных были зафиксированы источник G22,
runtime, транспорт, список URL, способ упаковки, остановка и критерии.
Нативная цель должна была содержать проверяемое свойство, строгий порог успеха,
полезность и ссылки минимум на три наблюдения из двух новых URL.

Оператор выбрал широкую смесь источников и обеспечил доставку. Выбор дефицита
оставлен существующему ядру. Исполняемый код ядра, лимиты памяти и прежние
задачи не изменялись. Новых событий `tasks` — **0**.

Заморозка опубликована в commit
`e4ff470b97447240019edae2c1035f2576268fc2` до первого запроса;
локальный commit с тем же tree — `4154316b1b62f7b52263e9ecaf083e52fe7072d0`.
Сопоставление находится в [code-freeze.json](code-freeze.json),
критерии — в [protocol.json](protocol.json).

## Что действительно дошло до ядра

20 сентября 2026 года, 20:27:55–20:28:48 UTC, получены **16/16 ответов HTTP 200**:
землетрясения USGS, космическая погода NOAA, таксономия GBIF, молекулы PubChem,
экономические показатели World Bank, метаданные GitHub и PyPI. Это шесть
предметных областей и четыре формата: JSON, CSV, текст и XML. Все 255 791 байт
исходных ответов сохранены в `sources/*.raw.gz`; их SHA-256 и время получения —
в [receipts.json](receipts.json). Все 16 хешей различны и отсутствуют в журнале
родительской G22. Свежесть означает новое получение; часть самих записей
описывает прошлые периоды.

Существующий `Kernel.study()` принимает максимум восемь документов по 8192
символа; пять мест уже заняты прежними знаниями G22. Фиксированный протокол
объединил по четыре источника в пакет: первые 1500 Unicode-символов каждого
ответа плюс нейтральные метаданные. Вопросов и ожидаемых ответов в пакетах нет.

Приняты **12 источников, 6 областей, 3 формата**, всего 15 966 исходных символов

не устанавливает поведение на неограниченном потоке полных структурированных
записей. Точный вход — [packets.json](packets.json).

## Наблюдение и технический вывод

Во всех шести вызовах выбора — до подачи, после каждого из четырёх пакетов и
после перезапуска — ответ одинаков:

```json
{"status":"IDLE","reason":"NO_SUPPORTED_ENDOGENOUS_DEFICIT"}
```

Трассировка показывает вызовы `autonomy.propose`, `autonomy.relation_goal` и
`library_evolution.transfer_goal`. В этих шагах не запускались отслеживаемые
`capability.diagnosis`, `specifications.learn` и оба механизма синтеза.
Исторический синтез при полном replay выполнялся отдельно, до включения
трассировки текущего решения.

**Вывод внешнего проверяющего, не самодиагностика Nova:** конструкторы целей
читают провалы прежних задач и записи принятых переносов; вновь сохранённый
`state["knowledge"]` не входит в их выбор. Поэтому увеличение объёма доставки
само по себе не добавляет отсутствующего перехода «наблюдение → проверяемое
предсказание → собственная ошибка → выбранный дефицит». Вторая обнаруженная
граница — бюджет восьми документов. Отказ четвёртого пакета не объясняет
отсутствие целей после первых трёх принятых пакетов.

Уверенность в этом выводе высокая для данного runtime и данного входа.
Системность какого-либо нового дефицита сама Nova не установила. Для следующей
инженерной итерации требуется механизм наблюдения и проверки собственных
предсказаний, связанный с целепостановкой; это направление исправления,
сформулированное проверяющим. Оно не засчитывается как достижение ядра.

## Проверки и границы доказательства

| Требование | Свидетельство | Результат |

| Сырые ответы совпадают с архивами; вход — их буквальные префиксы | `integrity.json`, 16 архивов, 4 пакета | PASS |
| Задачи и эталоны не добавлены | В журнале только 3 новых события `knowledge` | PASS |

| Прежние активные способности сохранены | `regression.json`: 192/192 случаев, 21 навык | PASS |
| Полный семантический replay в отдельном процессе | `cold-replay.json`, 72 события | PASS |

Спецификация автономного выбора дефицита **не выполнена**. Целостность
эксперимента и сохранение прежнего поведения подтверждены в Python 3.12.14.
Кандидата не было, поэтому fresh-blind проверка новой способности, её ablation,
admission, rollback нового поколения и цепочка из трёх поколений здесь
не выполнялись. Зелёные regression/replay не превращают этот результат в
доказательство автономного развития.

## Воспроизведение

Из корня репозитория, на Python 3.12, можно восстановить сохранённый журнал
без повторных сетевых запросов. Путь назначения должен быть новым:

```bash
python scripts/run_development_chain.py --restore experience/unlabelled-stream-v1/journal.json --state /tmp/nova-stream-replay.sqlite
python -m nova_core --state /tmp/nova-stream-replay.sqlite step
```

Фактический запуск зафиксирован в [run.log](run.log). Команды `collect`, `run`
и `replay` из `scripts/run_unlabelled_stream.py` завершились с кодом 0;
`replay` выполнялась новым процессом. Код 0 означает завершённый эксперимент,
его научный вердикт находится в [run-summary.json](run-summary.json).
`python scripts/verify_release.py` также завершилась с кодом 0: runtime 0.6.0,
20 совпадающих исходников. Повторное получение сети даст другие данные и будет
новым экспериментом, а не replay этого результата.
