# Отдельная проверка новых функций UCR 18

Источник — присланный `universal_code_reader-19.py`, внутренняя версия 18.0.
В интегрированной копии сохранены исправления Nova и исправлено игнорирование
seed в генераторе испытаний. Исходный файл пользователя не изменялся.

Протокол один раз запускает встроенную эволюцию двухзвенной грамматики UCR,
затем один раз вызывает `run_autonomous_novel_challenge_development(seed=18001)`.
Все задания происходят из ограниченного встроенного пространства шаблонов.
Цель, формула и ответы для основного прогона Nova этим опытом не задаются.

Получены четыре испытания; UCR выбрал дефицит `compose3-required`, добавил
правило трёхзвенной композиции и маршрут выбора этой стратегии. Итоговое
состояние содержит два правила грамматики, одну стратегию и два примитива:

| Примитив | Состав |
|---|---|
| `evolved.p_9b88b7bdc51e1288` | цифровой корень модуля числа → проверка нулевого бита |
| `evolved.p_0adb6afe55a80302` | цифровой корень модуля числа → число единичных битов → проверка первого бита |

Внутренний статус UCR — `ADMITTED`. Экспорт в `ucr.evolved-state/4` и загрузка
новым экземпляром прошли: результаты совпали в 16 проверках после восстановления.
Файл состояния — `evolved-state.json`, полный отчёт — `novel-report.json`.

## Что этот результат означает

Проверены работоспособность нового учебного механизма UCR и сохранение его
состояния. Выбор испытаний и стратегий уже использует внутренние hidden/fresh
выборки, поэтому повторные оценки на них не являются независимой проверкой.
Разные испытания также могут использовать одинаковые входные значения.

Эти примитивы не допущены в геном Nova. Активный поиск Nova использует UCR 18
с реестром собственных нативных операций и прежними критериями допуска.
Новое поколение Nova этим отчётом не объявляется. Её отдельное продолжение
сохранено в `experience/ucr18-integration`.

```bash
python scripts/run_ucr18_probe.py --output /tmp/ucr18-feature-probe --seed 18001
```
