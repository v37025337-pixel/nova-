# UCR участвует в развитии Nova: реальное продолжение G22

В runtime 0.8 ядро вызывает UCR как источник нативных программ. Это изменение
внесено разработчиком. Поиск кандидата выполняет UCR на обучающих примерах,
а фиксацию, исполнение и допуск контролирует ядро Nova.

Этот опыт продолжает все 116 событий `ucr-v16-integration` без изменения
предшествующей истории. Добавлены явный переход v7 → v8 и три обычных шага
ядра. Новые задачи, документы и свежие проверочные ответы не подставлялись.

## Что произошло

Nova сама выбрала пару `confidence → evidence_count` в
`/reader/passport/operators/*/role` из ранее сохранённого анализа UCR.
Ошибки предсказания были достаточны для постановки цели по существующему
правилу, но не доказывали предсказуемость или полезность этой связи.

| Этап | Результат |
|---|---|
| Выбор цели | `GOAL_FROZEN`, происхождение — наблюдения reader |
| Фиксация входов | `SEARCH_FROZEN`, 8 обучающих примеров |
| Поиск UCR | 24 + 336 + 2048 = 2408 деревьев, точного решения нет |
| Запасной нативный поиск | 10634 кандидата, решения нет |
| Контроль прежним синтезатором на той же выборке | 10634 кандидата, решения нет |
| Итог | `WITHHOLD / OBSERVATION_SEARCH_EXHAUSTED` |
| Новые навыки | 0; активна G22 |
| Регрессия | 192/192 примера, 21 навык |
| Журнал | 120 событий; исходные 116 событий сохранены точно |

Итог поиска, его источник, хеш обучающих строк и счётчики UCR записаны в
`actions.json` и в журнале. Свежих проверочных примеров UCR не видел.

## Что проверено отдельно

Учебный тест с пустой памятью получает от UCR реальную программу, фиксирует
её и допускает новый навык только после 16 невидимых для поиска примеров.
Проверены исполнение после перезапуска, отрицательный контроль, ограничение
бюджета, запрет неизвестных операций и запасной нативный поиск. Эти учебные
состояния не выдаются за новое поколение реальной G22.

123 локальных теста прошли. Статические хеши 22 файлов ядра и трёх файлов
инструментов проверены. Итог отдельного процесса воспроизведения сохранён
в `summary.json` и `restart-stdout.json`; CI повторяет восстановление архива.

## Граница результата

Разрыв между UCR и поиском ядра устранён: в этом опыте ядро использовало
сохранённые наблюдения reader и вызвало UCR для решения выбранной цели.
Дополнительная способность по сравнению с прежним поиском не получена.
Правило выбора первых 64 пар полей осталось прежним; оно может выбирать
связи без полезного предсказуемого закона. Автоматического переписывания
исходных файлов, расширения грамматики Nova или смены критериев допуска нет.

## Повторение

```bash
python -m unittest discover -s tests -v
python scripts/verify_release.py
python scripts/run_ucr_development.py --output /tmp/nova-ucr-development
```

Для исходного архива требуется Python 3.12. Runtime, SHA-256 родительского
файла и границы запуска зафиксированы в `protocol.json`. Скрипт не перезаписывает
существующее состояние или каталог результата.
