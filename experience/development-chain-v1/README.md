## Откуда данные и кто что сделал

Ассистент прочитал `package.json` через GitHub и подготовил задачи с эталонными
ответами. Из 48 запросов получено 45 подходящих снимков; их содержимое проверено
по Git blob SHA. Два файла не содержали имени пакета, один не удалось прочитать.
Все эти исходы сохранены в `sources.json`.

Использован 41 репозиторий: 30 для обучения/holdout пяти основных задач, шесть
для отрицательного контроля и пять для новых запросов. Ещё четыре подходящих
снимка не использовались. Имена и версии извлечены из настоящих upstream-файлов.
Входные JSON-документы собраны из этих полей оператором; это не утверждение,
что само ядро ходило в GitHub или изучало весь код этих проектов.

Каждому источнику заранее назначена одна роль. Входы обучения и holdout
не пересекаются ни внутри задачи, ни между задачами. Пять источников запросов
не встречаются в обучении или holdout. Эталонные ответы вычислены оператором
до запуска; поисковик получает только обучающие примеры.

Программы сгенерировал NOVA. Готовый Python-кандидат от внешней LLM в ядро не
передавался. Цели и порядок при равном дефиците определены подготовленной
программой испытания и действующей политикой выбора задач. Самостоятельное
изобретение целей и общего языка программирования этим опытом не доказано.

Прогон занял около 32,3 с; проверка копии отдельным процессом — около 15,7 с в
данной среде. Это также показывает текущую стоимость полного повторного синтеза
при восстановлении истории; результатов масштабирования здесь нет.

Для продолжения используйте команду восстановления из корневого README.
Полная контрольная точка — `journal.json`; состояние не зависит от повторной
доступности GitHub. Для повторения того же опыта в новый файл и каталог:

```bash
python scripts/run_development_chain.py --protocol-commit 14b96166eff3631610ae272da24352cb29382ec0 --state state/repeat.sqlite --output experience/development-chain-v1-repeat
```

Повтор на тех же данных проверяет воспроизводимость и не считается новым
независимым обучающим экспериментом. Эта контрольная точка закреплена за Python
3.12 и исходниками runtime из `c233ff5c`.

## Файлы доказательств

- `protocol.json`, `sources.json`, `corpus.json`, `queries.json` — зафиксированные входы.
- `steps.json` — настоящие решения, сгенерированный source, genealogy и gate каждой попытки.
- `genes/g4.py`–`genes/g8.py` — точные экспорты пяти созданных ядром программ для просмотра; исполняемый источник истины остаётся в журнале.
- `query-results.json` — результаты дополнительных запросов.
- `genome.json`, `causal-memory.json`, `journal.json` — сохранённая линия развития.
- `restart-stdout.json`, `restart-stderr.txt` — вывод отдельного процесса проверки.
- `run-summary.json` — сводка исходов и фактических времён.
- `unit-tests.txt` — текущая регрессия и проверки восстановления контрольной точки.

Это успешная ограниченная цепочка развития генов-программ на подготовленных
задачах с внешними данными. Общий интеллект, сознание и самостоятельное
переписывание исполняющего движка по этому прогону не заявляются.
