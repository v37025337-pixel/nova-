# NOVA 1.1 — единое ядро с циклом от сырых наблюдений

Один журнал, геном, планировщик и память объединяют прежние 24 навыка и новый
механизм, полученный из неразмеченных байтов. Новый цикл получает только URL:
без task ID, примеров с ответами, выбора языка, reader или каталога прикладных целей.

Встроенное предпочтение задано разработчиком: точно сохранять наблюдения при
меньшей длине описания. Это необходимая исходная мотивация, а не самостоятельно
изобретённая система ценностей. Ядро измеряет дефицит, формирует конкретную цель,
обучает грамматику и компилирует её в новый исполняемый код.

## Проверенный сквозной цикл

| Переход | Реальный результат |
| --- | --- |
| Сырые наблюдения | HTTPS-байты curl и serde_json; декодирования языка и разбора исходников нет |
| Самоцель | Обнаруженная избыточность переходов байтов; цель сократить описание с точным восстановлением |
| Новый механизм | 189 выведенных из данных правил; скомпилированы прямое и обратное преобразования |
| Фиксация | Цель, программа, стоимость, известные источники и критерии записаны до transfer-загрузок |
| Transfer | Gson и Pydantic: 2/2 полных файла восстановлены побайтово; новая программа не обучалась на них |
| Польза на transfer | 154 238 → 117 372 байта с повторным начислением полной стоимости модели; выигрыш 36 866 байт |
| Ablation | Реальное исполнение программы без приобретённых правил: 154 442 байта; выигрыш исчез |
| Регрессия | 192/192 прежних ответов, 72/72 графовых случая, 4/4 новых байтовых наблюдения |
| Применение | Все четыре наблюдения сохранены новым механизмом и восстановлены через общую память |
| Общий геном | Unified U1 → U2; 24 → 25 приобретённых механизмов |

Новый активный каталог содержит две операции приобретённого механизма — упаковку
и восстановление. До admission их не было. Во время всего реального цикла функции
каталога, UCR-reader, графового парсера и графового выбора задач были заменены
проверками, которые прервали бы выполнение при любом обращении.

Грамматика строится из соседних символов: пары выбираются по частоте, новые символы
могут участвовать в следующих правилах. Среди префиксов обучения выбирается
наименьшее описание с полной стоимостью исполняемого артефакта. Начального словаря
фраз, типов файлов и правильных ответов нет. Ограничения: до 192 правил, до 128 байт
в раскрытии одного символа и до 262 144 байт на наблюдение.

## Что именно доказано

Это обучение нового байтового представления внутри предоставленного алгоритма
индукции. Готовый справочник целевых функций здесь не используется. Сам алгоритм,
компилятор, мотив экономии памяти и критерии admission написаны разработчиком.
Произвольная семантическая постановка задач и изобретение нового алгоритма обучения
этим опытом не доказаны.

Обычный zlib даёт на тех же transfer-файлах 34 794 байта, существенно лучше нового
механизма. Сравнение для admission относится к фактически имевшемуся способу
хранения сырых наблюдений, а не к лучшему известному компрессору. Ценность опыта —
сквозное обучение, перенос и применение, не рекорд сжатия.

Активные данные четырёх наблюдений занимают 323 505 байт; после преобразования и
учёта модели — 207 337 байт, на 35,9% меньше. Это размер полезной нагрузки и модели.
Журнал аудита сохраняет исходные захваты; размеры SQLite, JSON-обёрток, общего
bootstrap и инфраструктурного кода в эту метрику не включены.

## Запуск

Нужны Linux с seccomp и Python 3.12 для точного replay поставленного опыта.
Новые приобретённые программы исполняются в отдельных процессах без сети и файлов.
Интернет используется только транспортом сырых наблюдений.

```bash
python -m pip install .
nova --state /tmp/nova-u2.sqlite restore experience/raw-cycle-v1/live/journal.json.gz
nova --state /tmp/nova-u2.sqlite status
nova --state /tmp/nova-u2.sqlite verify
nova --state /tmp/nova-u2.sqlite recall 3 --output /tmp/recalled.bin
```

`init` начинает с проверенного U1: все 24 прежних навыка сохранены. Для собственного
цикла нужен JSON-массив новых публичных HTTPS URL. Ядро само использует первые два
успешных наблюдения для открытия дефицита, фиксирует кандидата и лишь затем получает
два новых источника для переноса. Известные источники, редиректы на известный origin
и повторённое содержимое не считаются свежими.

```bash
nova --state /tmp/new-cycle.sqlite init
nova --state /tmp/new-cycle.sqlite sense experience/raw-cycle-v1/live/urls.json
nova --state /tmp/new-cycle.sqlite run --steps 12
nova --state /tmp/new-cycle.sqlite export --output /tmp/cycle.json.gz
```

Адреса выше позволяют повторить сетевой опыт на текущих версиях файлов; содержимое
интернета может измениться. Точное воспроизведение использует сохранённый журнал.
Если пул исчерпан, ядро ждёт дополнительных URL через `sense`, сохраняя замороженную
программу. Если перенос не дал выигрыша, кандидат удерживается от admission,
проверочные данные отмечаются использованными. Отсутствие дефицита даёт `IDLE`.

`goal`, `inspect`, `invoke`, `learn`, `study`, `engine-trial`, `observe-state` и другие
прежние команды остаются в едином runtime. Пока идёт новый сырой цикл, его источники
защищены от побочной загрузки через другие способности. После цикла обычная очередь
снова доступна. Работа конечна; фонового автономного процесса здесь нет.

## Проверка и история

```bash
python -m unittest discover -s tests -v
python scripts/verify_raw_cycle.py
python scripts/verify_unified.py
python scripts/verify_nova_next.py
python scripts/verify_release.py
```

`verify_raw_cycle.py` полностью воспроизводит решения без сети, повторяет общий
regression, исполняет приобретённый механизм, проверяет точное восстановление и
откат к U1. Откат сохраняет сведения об увиденных и использованных данных и
восстанавливает доступ к байтам даже после удаления нового механизма из каталога.

U1 и его проверяющий код сохранены в `experience/unified-v1/frozen-runtime.tar.gz`.
`verify_unified.py` проверяет SHA-256 архива и запускает прежний verifier в отдельном
временном каталоге. Исторические журналы не приписываются изменённому runtime.
`bootstrap-v2.json.gz` — явно доверенный корень нового релиза, полученный полным
семантическим replay U1. Пересборка-проверка: `python scripts/build_raw_checkpoint.py`.
Прежний `bootstrap.json.gz` и все родительские журналы сохранены.

Полученные SHA-256 и HTTPS-захваты — локальные свидетельства воспроизводимости,
не подписи внешних серверов. Разные репозитории не доказывают отсутствия общего
кода или происхождения. Два transfer-файла — два файла, а не десятки независимых
испытаний. Общий интеллект, сознание и неограниченное самоизменение не заявляются.
