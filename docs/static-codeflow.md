# Статические графы UCR v25

Файл `experience/codeflow-v25-input/ucr_v25_real_flow_cores.json` — точная
копия присланных данных. Он содержит графы requests (заявлена версия 2.32.5,
66 узлов и 73 связи) и urllib3 (заявлена версия 2.7.0, 56 узлов и 62 связи).
Исполняемый reader Nova остаётся UCR 18.0; номер v25 относится к поставке данных.

`scripts/import_static_codeflow.py` проверяет строгий JSON, схему, уникальность
и согласованность идентификаторов, типы связей и существование обоих концов
каждой связи. Предел входа — 262144 байта. Циклы допустимы как описание рекурсии.
Функции библиотек при импорте не выполняются.

Прямое чтение всего файла через `Kernel.observe()` достигает предела 128
записей и теряет часть данных. Импортёр делит узлы и связи на четыре полных
документа, проверяет отсутствие усечения и точное совпадение всех 257 записей
после штатного разбора Nova. Все части сохраняют один URL исходного файла
в конкретном Git commit и исходный SHA-256. Четыре части не считаются четырьмя
независимыми источниками.

Названия версий и статические связи сохраняются как пользовательские данные.
Соответствие исходникам upstream и реальному выполнению не проверялось.
Название проекции `intermodule-causal-core` не является доказательством
причинности. Импорт добавляет наблюдения; новый исполняемый навык требует
обычного отдельного цикла поиска и допуска Nova.

Запуск из репозитория:

```bash
python scripts/import_static_codeflow.py experience/codeflow-v25-input/ucr_v25_real_flow_cores.json --parent experience/ucr18-continuation-20260921/journal.json.gz --source-commit 8814b83cf830935c119ac789a5fc262d6bd4e7d8 --output /tmp/nova-codeflow-import
```

Указанный commit содержит точный входной файл. Необязательный `--checkpoint`
принимает SQLite-копию того же родительского
журнала: перед записью новых событий ядро полностью воспроизводит её и проверяет
равенство закреплённому родителю. Это сокращает перенос состояния; проверка
истории сохраняется. После импорта отдельный процесс проверяет полный журнал.
`--replay-timeout` задаёт время ожидания проверки (по умолчанию 600 секунд).
Тайм-аут записывается как ошибка, а результаты самого импорта сохраняются.
